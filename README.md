# Pixel Press

Client-side exact file size optimizer & cropper. 100% private — zero uploads, everything runs in your browser.

## Use

Open `index.html` in any modern browser, or serve it statically:

```sh
npx serve .
```

Then:

1. Drop or pick an image (JPG, PNG, WebP, BMP, GIF)
2. Drag to crop, optionally rotate / flip / straighten
3. Set max size (KB/MB), output format (JPEG / WebP / PNG), optional resolution
4. Compress to Exact Target → download the result

Single file, no dependencies, no build step.
